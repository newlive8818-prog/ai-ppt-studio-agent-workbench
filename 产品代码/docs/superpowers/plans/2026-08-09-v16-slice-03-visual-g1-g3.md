# v1.6 Slice 03 Visual, G1, G2, and G3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the authoritative strict-route-B visual chain from confirmed G0 through complete visual contracts, native-first anchors, four-target same-hash evidence, internal G1/G2, professional visual review, and chat-only G3.

**Architecture:** Visual artifacts are immutable schema 3.0 objects linked to the frozen content blueprint. `VisualService` registers each ordered result, while `GateEvaluator` alone computes G1/G2/G3 transitions. Target evidence is an explicit evidence matrix; automated tests prove rejection behavior but never create a real compatibility claim.

**Tech Stack:** Python standard library, `unittest`, JSON/SHA-256, existing Node MCP and React review surface.
