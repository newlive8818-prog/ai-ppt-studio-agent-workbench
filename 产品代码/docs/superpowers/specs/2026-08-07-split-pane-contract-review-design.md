# 正文优先的合同审阅目录设计

## 状态与边界

- 状态：`已确认`，用户选择方案 A，用于更新探索性 HTML 原型和 UI 唯一基线。
- 目标原型：`产品代码/prototypes/06-fullscreen-contract-review-exploration.html`。
- 适用范围：专业审阅模式、完整 PC 页面、Codex 分屏浏览区和更窄的侧栏视口。
- 保持不变：内容/视觉合同、连续阅读、精确标记、显式保存、G0/G3 等业务合同。
- 最终 PPTX 验收仍由 Codex 对话与 PowerPoint 完成，不放入本页。

## 问题诊断

目录是低频定位工具，正文是主要阅读对象。目录常驻会持续占用 210–260px，特别是在 Codex 对话与审阅页并排时，正文还会被浏览区、页面外边距和纸面内边距多次压缩。问题是导航占位方式，不是正文字号。

## 已确认方案

所有模式统一采用“默认折叠、按需覆盖”的目录：

- 页面首次打开时目录关闭，不读取或记忆上一次的开启状态。
- 页面布局不再为目录保留常驻列，也不保留窄目录轨道。
- 顶部始终提供带文字的“目录”按钮，并显示当前是内容目录还是视觉合同目录。
- 点击按钮后，目录从左侧以覆盖抽屉出现；正文宽度和横向位置保持不变。
- 点击目录项完成定位后自动关闭；点击背景、关闭按钮或按 `Escape` 也可关闭。
- 目录抽屉与标记抽屉互斥，避免左右遮罩同时出现。
- 内容审阅与视觉合同切换时，目录保持关闭，并同步标题和条目。

## 各模式布局

### 完整 PC 与专业审阅模式

- 目录默认折叠，不因视口足够宽而恢复常驻。
- 正文使用全部可用宽度；宽屏原有双列内容结构可以保留。
- 目录覆盖抽屉宽度不超过 320px，也不超过当前视口宽度减 24px。

### Codex 分屏浏览区

- 目录同样默认折叠，以覆盖抽屉打开。
- 主阅读区缩减外边距并使用单列信息结构，优先保证长中文正文可读。
- 目录打开和关闭均不得触发正文重排、横向跳动或滚动位置变化。

### 更窄视口

- 不再显示强制拖宽或最小宽度遮罩。
- 目录仍由顶部按钮以覆盖抽屉打开，抽屉宽度随视口收缩。
- 本次只保证目录不占正文宽度；其他窄屏 Header 和内容排版优化另行治理，不夹带进本变更。

## 交互与可访问性

- “目录”按钮使用图标、文字和当前文档标签，不只使用图标。
- 抽屉打开时设置 `aria-expanded=true`，目录可见时设置正确的 `aria-hidden`。
- 抽屉打开后焦点进入第一个可用目录项；关闭后焦点返回“目录”按钮。
- 点击目录项后滚动到目标，目标获得可见焦点，随后关闭抽屉。
- 背景遮罩只覆盖正文区域，不遮盖顶部关闭入口。

## 验收条件

1. 1440×1100、1000×1000 和 760×1000 视口首次打开时，目录均关闭且 `.workspace` 不为目录保留布局列。
2. 三种视口下“目录”按钮均可见，可打开和关闭覆盖抽屉；抽屉打开前后正文宽度与横向位置不变。
3. 点击目录项后页面滚动到正确目标，目录自动关闭；背景、关闭按钮和 `Escape` 也能关闭。
4. 内容审阅与视觉合同切换后，目录保持关闭，按钮标签、目录标题和目录项同步更新。
5. 目录与标记抽屉不能同时打开。
6. 页面不存在最小宽度提示或全屏阻塞遮罩，且无横向溢出由目录引起。
7. 区块标记、选中文字标记、显式保存和刷新持久化不回归。
